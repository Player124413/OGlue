# Sonic Heroes — экспериментальная сборка OGlue для Windows x64

Этот архив содержит `SonicHeroesPC.exe` и папку `game`, извлечённую из вашего ISO.
Исходный код рекомпиляции находится в **отдельном** артефакте
`SonicHeroes-PC-Recompilation-Source`.

## Важно о статусе

Успешная компиляция не означает, что игра проверена на играбельность. В текущем
OGlue есть исправления runtime для Heroes, но нет отдельного проекта Heroes с
адресами устройства D3D, fence-ожиданий и другими ручными правками. Этот host
автоматически подключает общий runtime, APU, pushbuffer-исполнитель и карту
kernel-ординалов, но не выдумывает отсутствующие адреса. Возможны падение,
зависание, отсутствие графики или звука. CI проверяет трансляцию и формат EXE,
а не прохождение игры.

## Запуск

1. Распакуйте архив целиком в локальную папку с коротким путём, например `C:\Games\SonicHeroes`.
2. Запустите `Launch-SonicHeroes.cmd`. Скрипт откроет игру и запишет вывод в `heroes-last-run.log`.
3. Нужны Windows 10/11 x64, видеокарта с Direct3D 11 и аудиоустройство. На Windows N
   может потребоваться компонент Media Foundation. Visual C++ Redistributable не
   нужен: CRT слинкован статически.

По умолчанию включены `RECOMP_AC97_READY=1`, `RECOMP_PB_EXEC=1`, `GENRY_GPU=1` и
`RECOMP_STUB_LOG=1`. Явно заданные переменные окружения не перезаписываются.
Сохранения общий runtime размещает в `%LOCALAPPDATA%\xboxrecomp`.

Управление клавиатурой: Enter — Start, Backspace — Back, WASD — стик,
Z/X/C/V — A/B/X/Y, Q/E — White/Black, 1/3 — курки, стрелки — крестовина,
F11 или Alt+Enter — полный экран. XInput-геймпад подключается автоматически.

## Если не запускается

Смотрите `heroes-last-run.log`, `xbox_kernel.log` и артефакт
`SonicHeroes-PC-Diagnostics` того же запуска workflow. Строки `[ICALL]`,
`[STUB]`, `[UNIMPL]` и `[CRASH]` указывают на недостающую интеграцию. Не смешивайте
`game` и EXE из разных запусков: host сверяет SHA-256 `default.xbe` с кодом.

Артефакты содержат производный код и данные вашей копии игры. Не публикуйте их
и не используйте публичный репозиторий для чужих образов. Срок хранения выбран
в форме запуска; GitHub также применяет ограничения репозитория.
